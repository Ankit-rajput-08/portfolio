Inventory Booking & Flash Sale Platform

Java 21 Spring Boot 3 Spring Security Redis Redisson Kafka MySQL MongoDB JWT Docker
  • A scalable backend platform simulating the architecture and challenges of a high-traffic flash sale e-commerce system — user management, product catalog, inventory, time-bound bookings, orders, and payments end to end.
  • Redisson distributed locks protect inventory operations from race conditions, preventing overselling when multiple users buy the same limited-stock product at once; Redis handles caching and high-speed access.
  • Apache Kafka drives asynchronous, event-driven order and notification workflows, decoupling slow work from fast API responses.
  • MySQL handles transactional business data while MongoDB stores audit and payment logs separately from the core transactional workload.
  • Secured with Spring Security, JWT authentication, BCrypt password hashing, role-based authorization, and request validation; the full stack is containerized with Docker and Docker Compose.

Distributed Job Queue System

Java 21 Spring Boot 4.0.4 Redis 7 MySQL 8.0 Lua Docker
  • A production-grade job queue built for massive concurrent submissions with strict SLA guarantees — traditional queues fail under this kind of load; this one guarantees zero job loss with sub-second response times.
  • Three-tier priority system (PUBLIC / UNPAID / PAID) with adaptive processing guarantees ranging from 60s to 300s SLAs per tier.
  • Lua-script-based atomic operations on Redis eliminate race conditions; automatic crash detection and recovery sustain a 99.9%+ job completion rate.
  • Adaptive scheduling adjusts job acceptance in real time based on system health metrics; worker thread pools process jobs in parallel while Redis sorted sets handle millions of queued jobs without degrading.
  • Heartbeat monitoring tracks job processing with millisecond precision, and containerized deployment ships with health checks and service orchestration.

Result: processes thousands of concurrent jobs with automatic recovery, zero manual intervention, and guaranteed SLA compliance.
